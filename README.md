# AI Based Maize Disease Detection 🌽

This project detects maize leaf diseases using Deep Learning (CNN) and provides treatment recommendations.

## Author
Anitha Reddy

## Project Description
Farmers often struggle to identify crop diseases early.  
This system helps detect maize leaf diseases automatically using a Convolutional Neural Network (CNN).

The user can upload or scan a maize leaf image and the system will:

- Detect the disease
- Show prediction accuracy
- Suggest treatment recommendations
- Provide voice assistance

## Technologies Used

- Python
- TensorFlow / Keras
- Flask
- HTML
- CSS
- Bootstrap
- JavaScript

## Dataset

PlantVillage maize leaf dataset containing:

- Cercospora Leaf Spot
- Common Rust
- Northern Leaf Blight
- Healthy Leaves
